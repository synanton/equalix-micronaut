# Samples

Runnable walkthroughs for the common paths. All assume a local instance with
`EQUALIX_API_KEY=changeme` on port 8080.

## [REST ingest](rest.md)

Create and inspect tasks through the REST API.

## [Echo executor](executor.md)

A minimal stub executor that accepts tasks and reports completion.

## [Sequential pipeline](sequential.md)

Ordered execution with dependency pass-through.

## [Kafka ingest](kafka.md)

Produce tasks to the ingestion topic and watch them schedule.
